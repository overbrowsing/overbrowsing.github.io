    A well-known URI capability descriptor for web archives

    web-archive.txt is an open specification for web archive interoperability, defining a human- and machine-readable plain-text descriptor published via the Well-Known URI pattern (RFC8615). It provides a consistent way for archives to publish identity, scope and access interfaces while enabling discovery and verification of programmatic endpoints.
