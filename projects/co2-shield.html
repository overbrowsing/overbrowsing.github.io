    Display the impact of your gitHub project as a Shields.io badge

    The CO₂ Shield allows you to assess the environmental impact of your project's web page and showcase it in your GitHub project as a Shields.io badge. It is powered by Beacon, which utilises the OneByte model developed by The Shift Project to calculate emissions. You can learn more about the project or contribute by submitting a pull request on GitHub.

    To get started, enter the URL, press 'Enter' or click 'Submit', then copy and paste the markdown snippet into your documentation.
